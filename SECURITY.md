# Security Policy

## Supported Versions

Only the latest active deployment of OVIC Labs is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

OVIC Labs takes security seriously. If you discover a vulnerability or potential security risk in our autonomous systems, control software, or digital platforms, please report it immediately.

**Do not file a public issue on GitHub.**

Please report your findings privately via email to:
* **security@oviclabs.com**

### Our Security Commitment

1. **Acknowledgment**: We will acknowledge your report within 24 hours.
2. **Triaging**: We will triage the vulnerability and assess its operational impact within 72 hours.
3. **Remediation**: We will keep you updated as we prepare a patch or workaround.
4. **Attribution**: Once patched, we will publicly credit you for the disclosure (if desired).

Thank you for helping keep OVIC Labs secure and reliable.
